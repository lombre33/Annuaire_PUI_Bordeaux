# Version 1.5.0 — Valeurs cochées en tête de menu + badge de comptage (voir CHANGELOG.md)

Dans chaque menu de filtre, les valeurs cochées remontent en tête (reste trié
alphabétiquement en dessous) et le bouton du filtre affiche un badge avec le
nombre de valeurs cochées — que le clic vienne de la case à cocher, du badge
établissement d'une carte, ou d'un tag de carte. Mise à jour ciblée du menu
concerné uniquement, sans reconstruire tout le DOM des filtres. Voir
`TESTING.md` pour le protocole de test complet.
